# Repository guidelines

Independent public repository for the accepted X-T30 II / 2.06 RAM patch. Read README.md and docs/DEVELOPMENT.md first. Keep the parent private research tree outside this repository; no sibling imports or symlink build inputs.

Device code and accepted payload hashes are frozen until a reviewed change has matching offline/build/device evidence. Preserve transport retirement, exact address ownership, native permissions restoration and same-installation probe/apply checks. New wrappers are host code and need explicit fresh-state checks; old receipts never count as current camera state.

Do not commit official DATs, decoded firmware, RAM/code capture binaries, media, live installation receipts, credentials, virtual environments or build outputs. Local reference inputs are generated by tools/prepare.py and ignored. CI never uploads private inputs. Artifact publication uses an explicit tracked-file inventory, includes license notices, source and SHA256SUMS, and excludes .git and ignored files.

Run python tools/check.py --payloads-only without reference inputs. Full offline regression needs the exact user-provided DAT and must never import the live USB transport. Compilation output belongs in build/, separate from frozen payloads/. No device or persistent operations without explicit task authorization.
